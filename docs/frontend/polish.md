# План доопрацювання React-адмінки

Цей документ фіксує погоджені інкременти для підготовки адмінки до презентації. Після кожного кроку виконується візуальна перевірка та створюється окремий коміт.

## 1. Брендинг середовищ

- Додати змінну `VITE_APP_VARIANT`.
- Відображати `Orest Web` для `VITE_APP_VARIANT=web` та `Orest Local` для `VITE_APP_VARIANT=local`.
- Оновити назву на екрані входу та в лівій панелі.

Візуальна перевірка: запустити застосунок із кожним значенням змінної та перевірити обидва місця відображення.

Коміт: `feat(ui): add environment-specific Orest branding`

## 2. Спільна навігація

- Прибрати індикатор готовності з верхньої панелі.
- Перенести кнопку «Вийти» в нижню частину лівої панелі.

Візуальна перевірка: перевірити три вкладки, вихід із сесії та вигляд на вузькому екрані.

Коміт: `feat(ui): move logout to sidebar`

## 3. Базове покращення AI-вкладки

- Відображати в полі «Місяць для підказок» тільки місяці, у яких є транзакції.
- Зробити кнопку «Прикріпити чек» блідо-зеленою.
- Після вибору чека заповнювати поле повідомлення текстом «Проаналізуй прикріплений чек і підготуй чернетку витрати.», не перезаписуючи вже введений текст.
- Деталізувати статуси недоступних чернеток: скасована, термін дії минув, помилка обробки.

Візуальна перевірка: вручну перевірити кожен сценарій на вкладці AI-помічника.

Коміт: `feat(ai-ui): improve receipt and draft workflow`

## 4. Новий діалог

- Реалізувати кнопку «Очистити чат» як створення нового порожнього діалогу.
- Зберігати попередню історію в БД; не видаляти її.
- Додати підтвердження дії та серверний тест.

Візуальна перевірка: надіслати повідомлення, почати новий діалог, переконатися, що інтерфейс порожній, перезавантажити сторінку та перевірити, що відкривається новий діалог.

Коміт: `feat(ai-chat): start a new conversation`

## 5. Керовані AI-підказки

- Додати таблицю та API для спільних AI-підказок.
- Замінити набір кнопок підказок на dropdown.
- Для користувача з роллю `admin` додати створення і видалення підказок.

Візуальна перевірка: перевірити список, вибір підказки, додавання та видалення адміністратором, а також недоступність редагування для користувача без прав.

Коміт: `feat(ai-chat): manage shared prompt suggestions`

## 6. Фінальна перевірка

- Перевірити адаптивність і регресії на всіх трьох вкладках.
- Зібрати React-проєкт і запустити релевантні серверні тести.

Коміт (лише якщо з'являться виправлення): `fix(ui): polish admin dashboard presentation`
